# Обработка адресов доставки

## Формат данных

Бэкенд отправляет в Saby Service два поля для адреса доставки:

### 1. `addressJSON` (string)
Структурированный адрес в формате JSON-строки.

**Пример успешного ответа от Saby API:**
```json
{
  "Address": "Ярославль, Московский проспект, д. 12А",
  "Coordinates": {
    "Lat": 57.6110031848633,
    "Lon": 39.8815185887695
  },
  "Flat": "123",
  "Entrance": "2",
  "Floor": "4",
  "DoorCode": "123",
  "Locality": "Ярославль"
}
```

**Пример fallback (когда API недоступен):**
```json
{
  "Address": "Ярославль, Кондратово, Садовое кольцо, 14",
  "Locality": "Ярославль"
}
```

### 2. `addressFull` (string)
Полный адрес в виде простой строки.

**Пример:**
```
Ярославль, Московский проспект, д. 12А
```

## Логика обработки

### Для доставки (isPickup = false)

1. **Попытка получить структурированный адрес от Saby API**
   - Вызывается `getAddressJSON(addressString)` из `addressService.js`
   - API возвращает массив возможных адресов
   - Берется первый (наиболее подходящий) адрес

2. **Fallback при ошибке API**
   - Если API недоступен или возвращает ошибку
   - Создается базовая структура с полем `Address`
   - Пытается извлечь город из первой части адреса (эвристика)
   - Если город определен, добавляется поле `Locality`

3. **Валидация перед отправкой**
   - Проверяется, что `addressJSON` - непустая строка
   - Проверяется, что `addressFull` - непустая строка
   - При несоответствии выбрасывается ошибка

### Для самовывоза (isPickup = true)

```javascript
addressJSON = JSON.stringify({ isPickup: true });
addressFull = '';
```

## Формат ввода пользователем

Пользователь должен вводить адрес в формате:
```
Город, улица, дом, квартира
```

**Примеры:**
- `Ярославль, Кондратово, Садовое кольцо, 14`
- `Ярославль, Московский проспект, д. 12А, кв. 5`

## Логирование

При обработке адреса логируются следующие данные:

1. **Запрос к API:**
   ```
   🔍 Запрос addressJSON для адреса: Ярославль, Кондратово, Садовое кольцо, 14
   ```

2. **Успешный ответ:**
   ```
   ✅ addressJSON получен: {"Address":"...","Locality":"..."}
   ```

3. **Fallback:**
   ```
   ⚠️  Используется fallback addressJSON: {"Address":"...","Locality":"..."}
   ```

4. **Данные перед отправкой в Saby:**
   ```
   📍 Данные адреса для отправки в Saby:
   {
     addressJSON: '{"Address":"...","Locality":"..."}',
     addressFull: 'Ярославль, Кондратово, Садовое кольцо, 14',
     addressJSONType: 'string',
     addressFullType: 'string'
   }
   ```

5. **Delivery данные в payload:**
   ```
   🚚 Delivery данные:
   {
     isPickup: false,
     addressJSON: '{"Address":"...","Locality":"..."}',
     addressFull: 'Ярославль, Кондратово, Садовое кольцо, 14',
     paymentType: 'card'
   }
   ```

## Переменные окружения

```env
# URL API для получения структурированных адресов (опционально)
SABY_ADDRESS_API_URL=https://link.saby.ru/article/...

# API ключ для Saby Address API (опционально)
SABY_API_KEY=your_api_key_here
```

## Обработка ошибок

### Ошибка "Maximum number of redirects exceeded"
- Проблема с URL API или сетевыми настройками
- Используется fallback логика
- Проверьте `SABY_ADDRESS_API_URL` в .env

### Ошибка "addressJSON должен быть непустой строкой"
- Не удалось получить адрес ни от API, ни через fallback
- Проверьте, что пользователь ввел адрес
- Проверьте логи для деталей

### Ошибка "addressFull должен быть непустой строкой"
- Аналогично addressJSON
- Проверьте входные данные
