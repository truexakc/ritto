# Поиск в каталоге

## Описание

Реализован функционал поиска товаров по названию и описанию в каталоге.

## Функциональность

### Бэкенд (saby-service)

Эндпоинт `GET /api/catalog/products` поддерживает параметр `search`:

```bash
GET /api/catalog/products?search=роллы
GET /api/catalog/products?hierarchical_parent=123&search=филадельфия
```

Поиск выполняется по полям:
- `name` - название товара
- `description` - описание товара

Поиск регистронезависимый (ILIKE в PostgreSQL).

### Фронтенд

#### 1. Поиск в хедере

**Десктоп:**
- Иконка поиска в правом верхнем углу
- При клике открывается поле ввода
- После ввода запроса и нажатия Enter перенаправляет на страницу каталога с параметром поиска

**Мобильная версия:**
- Иконка поиска в мобильном меню
- Поле поиска в верхней части мобильного меню
- После ввода запроса перенаправляет на каталог

#### 2. Поиск на странице каталога

- Поле поиска расположено под заголовком "КАТАЛОГ"
- Поддерживает комбинацию с фильтром по категориям
- Отображает количество найденных товаров
- Кнопка очистки поиска (X)
- URL синхронизируется с состоянием поиска

## Примеры использования

### Только поиск
```
/catalog?search=роллы
```

### Поиск + категория
```
/catalog?hierarchical_parent=123&search=филадельфия
```

## Технические детали

### API

**Файлы:**
- `front/src/services/product.ts` - обновлен метод `getProducts()`
- `front/src/hooks/useProducts.ts` - обновлен хук для поддержки параметра search

**Изменения:**
```typescript
// Было
getProducts(hierarchicalParent?: string)

// Стало
getProducts(params?: { hierarchicalParent?: string; search?: string })
```

### UI компоненты

**Файлы:**
- `front/src/pages/Catalog.tsx` - добавлено поле поиска и логика
- `front/src/components/Header.tsx` - добавлена иконка и поле поиска

**Особенности:**
- Поиск работает по нажатию Enter или кнопки поиска
- Автоматическая очистка при переходе на другую страницу
- Сохранение состояния в URL для возможности шаринга ссылок
- Анимация появления результатов поиска

## Миграция с старого API

Старые эндпоинты `/api/products` были удалены. Теперь используется:
- `/api/catalog/categories` - список категорий
- `/api/catalog/products` - список товаров с фильтрацией и поиском
- `/api/catalog/products/popular` - популярные товары

Все запросы проксируются через nginx напрямую на saby-service (порт 8080).
